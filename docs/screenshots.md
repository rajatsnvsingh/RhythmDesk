# Screenshot provenance & refresh

[Documentation index](README.md)

The images in `assets/screenshots/` are actual browser captures of Rhythm Desk's isolated demo, not UI mockups. Audio is generated by ffmpeg; artwork is generated by the test fixture. Northbound, Harbour Lines and The Satellites are sample artists. Queued/review sample jobs illustrate states; they are not evidence of a real catalogue match. Final-library publication is disabled in the demo.

## Create your own isolated demo

From the repository root, with dependencies and ffmpeg installed:

```bash
python app/demo.py --root .local/docs-demo
CURATOR_AUTH_REQUIRED=0 python app/server.py --root .local/docs-demo --port 8770 --demo
```

This authentication-free example is **only** for the local synthetic demo; the server defaults to localhost. On PowerShell set the environment variable separately with `$env:CURATOR_AUTH_REQUIRED='0'`. Never reuse a production root or publicly expose this demo.

To show the source picker, set `CURATOR_SOURCE_ROOT` to the absolute demo `rhythm-attic` directory and use a generic `CURATOR_HOST_SOURCE` display label. No actual music folder is needed. The demo generator keeps an existing demo unchanged; choose a fresh directory whose name includes `demo` for a clean regeneration.

Capture Overview, Incoming, Inspect and the drawer using the browser's screenshot mechanism. For manual controls, inspect Signals and open Manual metadata & artwork without submitting it. Check desktop and phone breakpoints, restore the viewport afterward, and save captures as JPEG. Avoid Settings captures that expose local personal paths. Do not rewrite screenshots to imply controls or successful publications that are not present.

Before committing images, inspect them for tokens, session cookies, real library titles, personal paths and private host addresses. Keep the demo banner visible when practical. Commit only the reviewed screenshots and banner; `.local` fixtures, state and credentials remain ignored.
