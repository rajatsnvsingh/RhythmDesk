Docker directory plan

Requires service recreation

Specify absolute paths on Nexus, not paths on this computer. Saving only records a plan. The app cannot remount Docker volumes or change the current publishing destination.

Download .env.paths
How to apply a directory plan safely
  1. Stop all curator services. Back up the state database.
  2. Prepare the new directories and restricted-user permissions. If staging or state changes, migrate their existing contents while services are stopped. Do not move or alter the sacred library automatically.
  3. Download .env.paths beside compose.yaml and your existing .env. Check the existing library path carefully.
  4. Recreate services with the extra file: docker compose --env-file .env --env-file .env.paths up -d --force-recreate
  5. Keep using both environment files (or merge only these three values into .env). Verify Current directories after restart before approving any release.

Host shell environment values can override these files. No tokens or credentials are included in the download.
